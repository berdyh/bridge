# @berdyh/bridge-protocol

The shared types and validators every other package builds on: the `bridge.json` discovery document, relay envelopes, sequenced and encrypted frames, SPAKE2 messages, the plugin manifest, device records and the RFC 8628 user code. It has no runtime dependencies. The client, the runner, the pairing client and the server kit all import it, so a document or frame that one of them writes is checked by the same validator in the others. Adapter and plugin authors read its types; app authors rarely import it directly, apart from small helpers such as `wordsOf`. Its pieces are used throughout the guides, for example [Write a plugin](../../docs/guides/write-a-plugin.md) for the manifest and [Write an adapter](../../docs/guides/write-an-adapter.md) for the relay shapes.
